# 蝇境：模拟 → 分镜 → 视频

入口：`/`。旧 `/world/` 链接跳转到首页。

## 已实现

- 完整连接组连续运行，窗口 120 ms，原生 WASM 状态仅在开始时重置一次。
- 8 个工程感觉通道：左右浆果距离、左右光照、边界、能量与基线。按索引循环映射到现有感觉神经元；这些不是经过生物学标定的嗅觉/视觉编码。
- 下行神经元的脉冲与膜电位增量，经过固定未训练投影，选择前进、左转、右转、梳理或停留。零信号时停留。环境规则限制活动边界、计算能量；不宣称具备生物行为能力。
- 保留膜电位、突触电流、延迟事件、随机数状态。无跨刷新神经状态持久化；页面关闭后停止。
- Three.js 实时画面、跟随视角、改变光照/浆果位置、浏览器录制 30 秒（可提前停止）。生成的是当前画面的录屏。
- 每约 4 秒模拟时间输出分镜（120 ms 窗口导致不超过一个窗口的偏差）；保留最近 60 段，可导出 JSON。
- 本地视频按文件名自然排序循环播放。当前为逐段加载，会有加载间隙，不保证无缝直播。
- 本地付费生成工作器：分镜 → Sora → 保存 MP4 → 抽取末帧 → 下一片段参考。末帧有助于衔接，但无法保证身份、场景、动作或几何完全一致。

## 运行

```sh
npm run dev -- --port 5190
```

打开 `/`，积累至少 4 秒世界时间，点击「导出分镜」。世界/神经模型时间 1:1；完整网络计算通常慢于真实时间。录制长度按实际墙钟计算。

离线检查，不产生 API 请求：

```sh
python3 scripts/world-video.py ~/Downloads/fly-world-plan.json --max-clips 3
```

确认视频服务权限与费用上限后，在本机配置 `OPENAI_API_KEY`，安装 `ffmpeg`。使用官方 OpenAI Python SDK：

```sh
uv run --with openai python scripts/world-video.py ~/Downloads/fly-world-plan.json --max-clips 3 --out output/fly-world --execute
```

`--execute` 才创建付费任务，默认最多 1 段；每段固定 sora-2 / 720p / 4 秒。`--max-clips` 是本批总片段上限，**不是金额限额**，运行前根据账户实际价格计算费用，并在服务端设置预算。没有启动常驻后台，也没有无限付费循环。密钥不进入网站或 Git。

中断后以相同参数运行会恢复已有 job ID；已有成片跳过。提交结果不明时保留 `submitting` 状态并停止，必须在服务端核对后修复记录，禁止盲目重试。意外强制终止留下 `.worker.lock` 时，先确认进程已结束再移除该锁。

把输出的 `clip-*.mp4` 多选载入网页即可顺序循环播放。`playlist.json` 可供将来的播放器服务读取。本轮未调用付费 API，真实模型权限、视觉质量和末帧衔接尚未验证。

## 仍需完成的长期运行部分

后台模拟状态持久化、连续队列、视频存储、播放预缓冲、每日金额限额和停机策略。当前部署为浏览器实验和可手动运行的有界视频生成工作器，不是无人值守的无限 AI 视频直播。

## 验证

`node scripts/check-world.mjs` 验证实际完整图的连续性、同种子可重复与断开突触后输出归零。`npm test` 检查世界适配器、资源哈希与原数值模型。

视频接口参考：[OpenAI video generation](https://developers.openai.com/api/docs/guides/video-generation)。真实数据来源与许可证见项目 README。

## 实时直播方向

Sora 工作器用于短片样片与离线导出。若要做持续视频流，优先按 [Truman World 调查](trumanworld-research.md) 验证 H3 Max Director；本次没有接通该付费服务。
